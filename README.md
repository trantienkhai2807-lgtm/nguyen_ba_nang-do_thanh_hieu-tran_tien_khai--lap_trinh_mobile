# 🛒 Tên Đề Tài: Xây Dựng App Bán Đồ Thể Thao

## 📖 Giới Thiệu Hệ Thống
Ứng dụng bán đồ thể thao là một nền tảng thương mại điện tử trên thiết bị di động, giúp người dùng dễ dàng tìm kiếm, mua sắm các thiết bị và trang phục thể thao. 

**Chức năng người dùng:**
- Đăng ký và đăng nhập tài khoản.
- Tìm kiếm sản phẩm thể thao theo danh mục.
- Xem thông tin chi tiết sản phẩm.
- Thêm sản phẩm vào mục yêu thích.
- Thêm sản phẩm vào giỏ hàng.
- Đặt hàng và thanh toán.
- Theo dõi thông tin đơn hàng.
- Cập nhật thông tin cá nhân.

**Chức năng quản trị viên:**
- Quản lý sản phẩm (thêm, sửa, xóa).
- Quản lý khách hàng.
- Quản lý đơn hàng.
- Theo dõi hoạt động của hệ thống.

## 🛠 Công Nghệ Sử Dụng
- **Frontend / Mobile:** React Native, JavaScript
- **Backend / Database:** NodeJS, Firebase

## ⚙️ Hướng Dẫn Cài Đặt

1. Clone dự án về máy của bạn:
   ```bash
   git clone https://github.com/trantienkhai2807-lgtm/nguyen_ba_nang-do_thanh_hieu-tran_tien_khai--lap_trinh_mobile.git
   ```
2. Di chuyển vào thư mục dự án:
   ```bash
   cd nguyen_ba_nang-do_thanh_hieu-tran_tien_khai--lap_trinh_mobile
   ```
3. Cài đặt các thư viện và dependencies:
   ```bash
   npm install
   ```

## ▶️ Hướng Dẫn Chạy Project

Chạy lệnh sau để khởi động dự án:
```bash
npx expo start
```
